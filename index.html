01 · OVERVIEW

Project Overview

The goal of this Google Summer of Code project is to develop a modular Switched Ethernet model capable of simulating 1, 10, and 40 GbE links, with MAC-based auto-learning of I/O ports, support for pluggable scheduling algorithms.introduce enhanced EthernetNetDevice model with point-to-point–like NetDevice abstraction for switched Ethernet, an EthernetChannel capable of simulating full-duplex mode of operation responsible for modeling transmission delay and errors.

The Ethernet implementation is organized into separate components for the channel, NetDevice, MAC and PHY layers. This separation allows the individual parts of the Ethernet stack to be developed, tested and extended independently while keeping their interactions close to the behavior of real Ethernet devices.

Ethernet Foundation

The EthernetChannel models the physical link connecting Ethernet devices. It provides configurable properties such as cable length and propagation speed. The channel is responsible for propagation between connected devices.

The EthernetNetDevice provides the ns-3 NetDevice interface and acts as the interface between the ns-3 networking stack and the Ethernet implementation.

The EthernetMac handles Ethernet frame processing and MAC-level transmission and reception. Supports Flow Control for Full-duplex.

The EthernetPhy represents the physical layer and coordinates transmission between the MAC and EthernetChannel.

Switched Ethernet

On top of the Ethernet foundation, the project introduces a modular Ethernet switch. The switch consists of a Switch object and multiple SwitchPort instances allowing multiple hosts to communicate through the switch. Supports MAC Address Learning and Forwarding, supports different scheduling policies

In Summary

The project progresses from a basic Ethernet link consisting of an EthernetChannel, EthernetNetDevice, EthernetMac and EthernetPhy to a multi-port switched Ethernet architecture. The resulting design provides a reusable and extensible foundation for Ethernet network simulations in ns-3.

02 · TIMELINE

Project Timeline

Community Bonding

Understanding the Architecture

Studied the existing ns-3 networking architecture and discussed the requirements, design decisions and implementation approach for the Ethernet module.

Phase 1

Ethernet Foundation

Developed the core full-duplex Ethernet model by implementing EthernetChannel and EthernetNetDevice, followed by separation of the Ethernet MAC and PHY layers. Added EthernetHelper and an Ethernet Ping example for configuration and connectivity testing. Implemented IEEE 802.3x PAUSE-based flow control and MAC control frame feature. Added tests for full-duplex communication, link speed, ifg and flow control along with PCAP tracing for the Ethernet Ping example.

Phase 2

Ethernet Switch

Extended the Ethernet model into a modular switched Ethernet architecture followed by implementation of the Switch and SwitchPort. Added MAC learning & lookup, forwarding, along with SwitchHelper and switched Ethernet Ping example for validation. Implemented a shared switch buffer and modular Switch Scheduler framework with FCFS scheduling, added tests for switch. Refactored queue management from EthernetNetDevice to EthernetMac

Final Phase

Testing & Validation

Added and executed tests and examples to validate Ethernet links, timing, switching, packet forwarding and end-to-end connectivity.
